используемые технологии:
• HTML5 — структура страниц сайта.
• CSS3 — оформление, адаптивный дизайн, анимации и стилизация элементов.
• JavaScript (Vanilla JS) — интерактивность сайта, слайдеры, модальные окна, фильтрация, поиск, lightbox, валидация форм.
• PHP — обработка форм обратной связи, чтение и запись данных заявок, вывод таблиц заявок.
• TXT (requests.txt) — файловое хранение заявок пользователей.
• HTTP / Localhost Server — локальный запуск и тестирование сайта.
• Responsive Web Design — адаптация сайта под ПК, планшеты и смартфоны.

Инструкция запуска:
1. Запустить сервер с помощью server.bat // понадобится PHP
2. Перейти на страницу в браузере по адресу: http://localhost:8080
3. Для просмотра заявок открыть страницу: http://localhost:8080/requests.php
